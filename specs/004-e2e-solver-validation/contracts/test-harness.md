# Interface Contract: Test Harness

## Python Validation Script (`compare_baselines.py`)

**Input Data**:
- `kpp_baseline.csv`: The trusted baseline from legacy KPP.
- `exaero_output.csv`: The output generated by the Exaero C++ box model.

**Output Protocol**:
- Process Exit Code `0`: RMSE is within acceptable bounds ($< 1 \times 10^{-6}$ relative, $< 1 \times 10^{-12}$ absolute), and Sparsity Pattern matches perfectly.
- Process Exit Code `1`: Validation failed. Dumps mismatches to `stderr`.

## Exaero C++ Box Model Runner

**Execution Protocol**:
- Must be executed directly via CMake `ctest`.
- Must instantiate a `Kokkos::DefaultExecutionSpace`.
- Must allocate simulated state arrays using `std::vector` host backing.
- Must wrap arrays in `Kokkos::View` with `Kokkos::MemoryUnmanaged` and `Kokkos::LayoutLeft`.
- Must write the final integration state to `exaero_output.csv`.
